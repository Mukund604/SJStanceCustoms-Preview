# SJ Stance Custom Wheels

A storefront for a custom wheel shop, with a wheel visualizer and a quote flow.

**[Open the live site](https://mukund604.github.io/SJStanceCustoms-Preview/)**

<a href="https://mukund604.github.io/SJStanceCustoms-Preview/"><img src="assets/readme/sjstance.png" width="100%" alt="SJ Stance Custom Wheels storefront" /></a>

## Stack

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. There's no build step.

## Run it locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
